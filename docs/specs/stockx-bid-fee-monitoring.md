# StockX 出价费率监控规格

## 目标

为 StockX 创建出价和修改出价任务增加可选的任务级费率监控，避免求购价高于现货卖出后的预计净回款。

- 任务级监控默认关闭；关闭时完整保留现有创建、追价和最高价上限逻辑。
- 任务级监控开启后配置商家手续费率、最低商家手续费和转账费率。
- 创建出价按每个目标 variant 的当前现货最低标价判断是否盈利。
- 修改出价支持 Excel 行级开关；任务还可选择处理 Excel 外的当前有效出价。
- 不盈利的 Excel 内修改出价和受控的 Excel 外出价统一压到 `$1`。

## 费率模型

任务参数：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `feeMonitorEnabled` | boolean | `false` | 是否启用费率监控 |
| `merchantFeeRate` | decimal | `0.07` | 商家手续费率，范围 `0~1` |
| `minMerchantFee` | decimal | `5.79` | 最低商家手续费，必须大于等于 0 |
| `transferFeeRate` | decimal | `0.03` | 转账费率，范围 `0~1` |
| `processOutsideExcel` | boolean | `false` | 仅修改出价使用；是否处理 Excel 外的当前有效出价 |

计算公式，金额按美分四舍五入：

```text
商家手续费 = max(现货标价 × 商家手续费率, 最低商家手续费)
转账费 = 现货标价 × 转账费率
可盈利求购上限 = 现货标价 - 商家手续费 - 转账费
```

求购价严格大于可盈利求购上限时视为不盈利；等于上限时允许。费率监控开启但取不到有效现货标价时，按无法证明盈利处理：创建任务跳过，修改任务压到 `$1`。

## 创建出价

1. API 接收任务级费率参数并保存到任务参数，历史重跑沿用原任务参数。
2. 继续按货号合并查询并复用 `searchExactItemWithPrice` 返回的 `standardPrice`，不新增逐 variant 行情请求。
3. 监控关闭时保持现有逻辑。
4. 监控开启时，在批量提交前比较 Excel 求购价和可盈利求购上限：
   - 盈利：正常创建出价。
   - 不盈利或无现货标价：跳过，不调用创建出价 mutation，并记录原因。

## 修改出价

Excel 新增 `费率配置是否启用` 列，支持 `是/否`、`true/false` 和 `1/0`。任务级监控开启时该列必填；监控关闭时允许为空并忽略。

每轮只完整分页读取一次当前有效出价；该查询已包含市场最高求购价和现货 `standard` 最低标价。构建出价 ID 映射后统一在内存决策，并继续使用每批最多 50 条的 `BulkUpdateBids`。

### Excel 内商品

- 行级费率关闭：保持现有逻辑，只按市场最高价加 `$1`，且不超过 Excel 最高价。
- 行级费率开启：
  - 先算实际候选价：已是市场最高时为当前价，否则为市场最高价加 `$1`。
  - 若追价候选超过 Excel 最高价，则保持当前价；但仍需检查当前价是否盈利。
  - 实际候选价盈利时按现有逻辑处理。
  - 实际候选价不盈利或缺少现货标价时，将出价改为 `$1`。
  - 已经是 `$1` 时不重复提交。

### Excel 外商品

仅当任务级费率监控和 `processOutsideExcel` 同时开启时处理：

- 不受 Excel 最高价限制。
- 已是市场最高时检查当前价；落后市场时以市场最高价加 `$1` 作为候选价。
- 候选价盈利则保持或追价；候选价不盈利或缺少现货标价则改为 `$1`。
- 已经是 `$1` 时不重复提交。

## 项目结构与代码风格

- `src/main/java/cn/ken/shoes/model/stockx/`：任务费率配置和值对象。
- `src/main/java/cn/ken/shoes/model/excel/`：修改出价 Excel 行级开关。
- `src/main/java/cn/ken/shoes/controller/`：multipart 参数解析与校验。
- `src/main/java/cn/ken/shoes/manager/`：任务参数持久化、重跑恢复和 runner 创建。
- `src/main/java/cn/ken/shoes/task/`：创建/修改出价决策和批量提交。
- `console/src/pages/task/history/`：任务表单、参数展示和前端测试。
- 复用现有 `BigDecimal`、不可变参数快照、批量 mutation 和任务明细记录模式。

## 测试策略

- 纯单元测试覆盖费率计算、边界相等、最低手续费和参数默认值。
- Runner 测试覆盖监控关闭兼容、创建跳过、Excel 行级开关、压到 `$1`、Excel 外商品和批量提交。
- Controller/Manager 测试覆盖参数校验、任务参数持久化及历史重跑。
- 前端源码测试和 TypeScript 构建覆盖条件表单、默认值、上传参数与参数展示。

## 边界

- 始终：默认关闭；所有费率参数后端校验；不增加逐商品行情请求；不超过 StockX 现有批量大小。
- 先询问：新增数据库字段、改变现有出价 API 契约之外的公共接口、生产部署。
- 绝不：监控关闭时改变旧行为；无盈利依据时继续提高受监控出价；触碰仓库现有未跟踪文件。

## 成功标准

- 创建和修改出价表单均可开启费率监控并使用 `7% / $5.79 / 3%` 默认值。
- 创建出价不会提交超过净回款上限的求购价。
- 修改出价可逐 Excel 行控制费率逻辑；不盈利时压到 `$1`。
- 可选择处理 Excel 外商品，且它们没有 Excel 最高价限制、只做不盈利压价。
- 每轮行情读取次数与现状同阶：创建按唯一货号查询，修改仅分页读取一遍全部有效出价。
- 历史重跑沿用原任务费率参数和 Excel 行级设置。
- 后端测试、前端测试、类型检查和构建通过。
