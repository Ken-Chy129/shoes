# 货号搜索上架双操作规格

## 目标

保留现有任务类型 `model_search`（货号搜索上架），新增两种互斥操作：

1. `fetch_price`（获取最低价）：按 Excel 的货号和尺码定位 StockX variant，返回现货最低价、Flex 最低价及 `variantId`。
2. `create_listing`（按指定价格上架）：按 Excel 的 `variantId`、目标上架价和上架数量直接创建挂单，不搜索商品、不查询得物价格、不判断盈利。

## 设计决策

- 不拆成两个任务类型。两步属于同一业务流程，共用账号、任务历史和导出入口；用任务参数 `operation` 区分即可。
- 第二步使用 `variantId`，不使用 `listingId`。`listingId` 只标识已经存在的挂单，创建新挂单的 StockX 接口要求 `variantId`。
- “商家数量”按 StockX 创建接口的 `quantity`（上架数量）实现。
- 获取价格的 Excel 中“货号”和“尺码”均必填；尺码继续兼容 US/EU 写法。
- 上架 Excel 优先使用第一步导出的文件。用户只需填写“目标上架价($)”和“上架数量”。
- 上架操作不再执行旧流程中的：在售去重、禁爬/不比价过滤、得物价格查询、盈利计算、最低价减一。

## Excel 契约

### 获取最低价输入

| 列名 | 必填 | 示例 |
| --- | --- | --- |
| 货号 | 是 | DD1391-100 |
| 尺码 | 是 | US 9 / EU 42.5 / 9 / 42.5 |

### 获取最低价输出 / 上架输入

| 列名 | 获取结果 | 上架必填 | 说明 |
| --- | --- | --- | --- |
| variantId | 自动返回 | 是 | StockX 尺码变体 ID |
| 品牌 | 自动返回 | 否 | 展示字段 |
| 产品名称 | 自动返回 | 否 | 展示字段 |
| 货号 | 自动返回 | 否 | 展示字段 |
| US码 | 自动返回 | 否 | 展示字段 |
| EU码 | 自动返回 | 否 | 展示字段 |
| 现货最低价($) | 自动返回 | 否 | Standard 最低价 |
| Flex最低价($) | 自动返回 | 否 | Flex/寄存最低价 |
| 目标上架价($) | 空白待填 | 是 | 正数美元价格 |
| 上架数量 | 空白待填 | 是 | 正整数 |
| 操作结果 | 自动返回 | 否 | 查询或上架结果 |

## 行为与校验

- 获取价格：同一货号尺码精确匹配；匹配不到或价格缺失也生成任务明细并写清原因。
- 上架：每行独立校验；无效行写任务明细，不阻止其他有效行提交。
- 同一 `variantId` 在一次上架文件中只能出现一次，重复行视为输入错误，避免重复提交。
- 批量提交每批最多 50 个 variant；每个请求项携带 Excel 指定的 `quantity`。
- 任务参数和原始 Excel 输入保存快照，支持暂停恢复和重跑。

## 兼容性

- 保留普通“搜索上架”任务 `listing` 的旧逻辑，不受影响。
- `model_search` 的历史任务仍可查看；旧参数没有 `operation` 时按旧上架逻辑恢复，避免升级后无法识别历史运行任务。
- 任务明细通用导出保持不变；`model_search + fetch_price` 使用专用 Excel 表头导出，以便直接作为第二步输入。
